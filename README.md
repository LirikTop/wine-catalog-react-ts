# 🍷 Wine Catalogue

Wine Catalogue is a web application designed for convenient viewing, searching, and filtering of wines.
The project was developed by a team that includes **Frontend**, **Design**, and **Backend** specialists.

## 📌 Project description
This is a wine catalogue where users can:
- Browse a list of wines with detailed information (name, country, variety, year, description).
- Search and filter wines by various criteria.
- View a page with a detailed description of the wine.
- Use an adaptive interface (convenient from a phone, tablet, and PC).

## 🛠️ Technologies used
### Frontend
- React + TypeScript
- React Router
- SCSS (depending on choice)
- Fetch API for working with data

### Backend
- Node.js / Express (or another stack if the backend does something else)
- REST API for processing requests
- Database (e.g. PostgreSQL / MongoDB)

### Design
- Layout in **Figma**
- UI/UX focused on simplicity and minimalism
